# Webyotic Landing Page

Responsive single-page agency website built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser.

## Before publishing
1. Open `index.html` and edit the `CONFIG` object near the bottom:
   - `email`
   - `phoneDisplay`
   - `whatsappNumber` (digits only, include country code)
   - `website`
2. Replace the placeholder email and phone text in the topbar/contact section through the same CONFIG-driven elements.
3. Add your verified project URLs and real screenshots in the portfolio section.
4. Remove any portfolio item that is not your own work or that you are not authorized to display.
5. Connect the enquiry form to a secure backend, CRM, or form service if you want leads stored automatically. The current form opens the visitor's email application.
6. Add your real privacy policy and terms pages before collecting personal data.
7. Test on mobile, desktop, and your hosting environment.

## Notes
- No fabricated testimonials, ratings, client logos, or performance claims are included.
- Portfolio cards are descriptive examples based on project types discussed; verify each one and add links/screenshots before presenting as completed client work.
- Pricing is intentionally quote-based rather than inventing rates.
